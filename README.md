# 量化因子研究项目

## 项目简介

本项目包含基于波动率和笔均量因子的双因子多空策略研究与实现，使用Python进行量化回测分析。

## 文件说明

| 文件 | 说明 |
|------|------|
| `波动率笔均量双因子多空策略.ipynb` | 核心策略Notebook，包含完整的数据处理、因子构建、回测分析流程 |

## 策略核心逻辑

### 1. 数据预处理
- 读取个股日线数据（CSV格式）
- 剔除涨跌停样本（当日无法交易）
- 计算日对数收益率
- 沪深300作为基准对比

### 2. 波动率计算
实现三种波动率测算方式：
- **5日滚动波动率**：简单历史波动率
- **EWMA波动率**：指数加权移动平均（λ=0.94）
- **GARCH(1,1)波动率**：MLE估计参数，输出长期无条件方差

选股使用GARCH动态波动率。

### 3. 笔均量因子（笔均量 = 成交量 / 成交笔数）
- MAD法去极值
- Z-score截面标准化

### 4. 因子检验
- **IC分析**：计算因子与下期收益的秩相关系数
- **IR比率**：IC均值/IC标准差
- **5分组回测**：验证收益单调性

### 5. 多空策略

| 策略 | 规则 | 调仓频率 |
|------|------|---------|
| GARCH单因子多空 | 每日GARCH波动率前10%做多、后10%做空 | 日频 |
| 双因子多空 | GARCH波动率+笔均量同时前20%做多、同时后20%做空 | 日频 |

### 6. 绩效指标
- 累计净值
- 年化收益率
- 夏普比率
- 最大回撤
- 胜率
- 换手率

### 7. 可视化
- 波动率对比图
- 分组收益图
- 净值对比图
- 回撤图

**注意**：所有图表仅在Notebook单元格内临时展示，不保存任何图片或文件。

## 回测结果与结论

### 数据概况
- **回测期间**：2023-01-03 至 2023-12-29
- **股票数量**：5,137只
- **交易日数**：242天

### GARCH(1,1)模型参数
- α均值约0.1，β均值约0.85，α+β接近0.95，符合金融时间序列波动聚集特征
- 长期无条件方差稳定，GARCH动态波动率能有效捕捉时变风险

### 因子有效性
- **GARCH波动率因子**：IC均值和IR比率显示因子与未来收益存在一定相关性
- **笔均量因子**：IC检验显示因子具有一定选股能力
- 5分组回测验证收益单调性，高分组与低分组收益差异明显

### 策略绩效
- **GARCH单因子多空策略**：日频调仓，双边成本0.1%，累计净值和夏普比率优于沪深300基准
- **双因子多空策略**：结合波动率和笔均量，策略稳定性提升，最大回撤控制较好
- **基准对比**：策略净值曲线与沪深300走势相关性低，具有一定市场中性特征

### 核心结论
1. GARCH动态波动率优于简单历史波动率，能更好刻画个股风险
2. 笔均量因子反映资金参与度和交易活跃度，与波动率因子互补
3. 双因子组合策略通过双重筛选，提升选股质量，降低回撤
4. 策略日频调仓换手率较高，实际应用需考虑冲击成本和流动性约束
